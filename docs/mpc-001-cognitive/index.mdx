# MPC-001: Cognitive Psychology, Learning and Memory

## Course Overview

This course provides a comprehensive understanding of cognitive psychology, focusing on learning, memory, intelligence, language, and problem-solving processes.

## Course Structure

### Block 1: Foundations
- Introduction to Cognitive Psychology
- Information Processing in Learning and Memory
- Neuropsychological Basis of Learning and Memory
- Models of Information Processing

### Block 2: Memory Systems
- Intelligence Theories - G and S Factor
- Multiple Theories of Intelligence
- Intelligence Testing
- Creativity and Problem Solving

### Block 3: Language and Cognition
- Language and Cognition
- Language Processing
- Multilingualism and Second Language
- Language and Speech Disorders

### Block 4: Problem Solving
- Nature of Problem Solving
- Stages of Problem Solving
- Theoretical Approaches to Problem Solving
- Impediments to Problem Solving

## Learning Objectives

By the end of this course, you will be able to:
- 🎯 Understand fundamental concepts in cognitive psychology
- 🎯 Analyze memory systems and information processing models
- 🎯 Evaluate theories of intelligence and creativity
- 🎯 Apply problem-solving strategies effectively

- **Assignment**: 30 marks
- **Total**: 100 marks
