### Answer (Section A — ~450 words):

**Data Organisation** involves arranging raw data in a systematic manner to facilitate analysis and interpretation. Two primary methods are used: tabular and graphical.

**Frequency Distribution:**

A **frequency distribution** is a table that shows how often each value or range of values occurs in a dataset.

*Ungrouped Frequency Distribution*: Lists each distinct value with its frequency. Suitable for small datasets or discrete variables with few possible values.

*Grouped Frequency Distribution*: Scores are grouped into class intervals. Used when the range of data is large.

**Steps in Constructing a Grouped Frequency Distribution:**
1. Find the range: Range = Highest score − Lowest score
2. Decide the number of class intervals (usually 8–15)
3. Compute the class interval width: i = Range / Number of classes
4. Set up class limits (from lowest to highest)
5. Tally the scores into each class interval
6. Count the tallies to get the frequency (f) for each interval

**Types of Frequency Distribution:**
1. *Simple frequency distribution*: Counts raw frequencies for each class.
2. *Relative frequency distribution*: Expresses frequencies as proportions or percentages of the total.
3. *Cumulative frequency distribution*: Adds each frequency to all preceding frequencies. Used for computing percentiles and medians.

**Four Major Statistical Techniques for Organising Data:**
1. *Frequency distribution tables* (as above)
2. *Graphical representation* (histogram, frequency polygon, ogive)
3. *Measures of central tendency* (mean, median, mode)
4. *Measures of dispersion* (range, variance, SD)

**Graphical Presentation of Data:**

1. *Histogram*: Bar graph where bars represent class intervals on the X-axis and frequencies on the Y-axis. Bars are adjacent (no gaps) for continuous data.

2. *Frequency Polygon*: A line graph connecting midpoints of the tops of histogram bars. Used to compare multiple distributions.

3. *Ogive (Cumulative Frequency Curve)*: A line graph of cumulative frequencies. Used to determine percentile ranks.

4. *Bar Chart*: Similar to histogram but for discrete/categorical data. Bars have gaps between them.

5. *Pie Chart*: Circular graph showing proportions. Each slice represents the percentage of total for a category.

6. *Scatter Plot*: Graph showing the relationship between two variables — each point represents one observation's scores on X and Y.
