### Answer (Section B or C — ~250 words):

**Multiple Regression:**

Multiple regression is an extension of simple linear regression in which **two or more predictor variables (X₁, X₂, ..., Xk)** are used to predict a single **criterion variable (Y)**.

*Equation*:
$$\hat{Y} = a + b_1X_1 + b_2X_2 + b_3X_3 + \ldots + b_kX_k$$

Where:
- a = regression constant (Y-intercept)
- b₁, b₂, ... = partial regression coefficients (slope for each predictor)
- Each b coefficient represents the change in Y for a one-unit change in that predictor, **holding all other predictors constant**

*Example*: Predicting academic performance (Y) from study time (X₁), intelligence (X₂), and motivation (X₃) simultaneously.

**Multiple Correlation (R):**

The **multiple correlation coefficient (R)** is the correlation between the observed values of Y and the predicted values of Y (Ŷ) obtained from the multiple regression equation. It represents the overall relationship between the criterion and all predictors combined.

*Properties*:
- R ranges from 0 to +1 (always positive, unlike Pearson's r)
- R² = **coefficient of multiple determination** — the proportion of variance in Y explained by all predictors together
- R ≥ r_YX for any single predictor (adding predictors never decreases R)

**Simple vs Multiple Regression:**

| Aspect | Simple Regression | Multiple Regression |
|--------|------------------|---------------------|
| Predictors | 1 | 2 or more |
| Equation | Ŷ = a + bX | Ŷ = a + b₁X₁ + b₂X₂ + ... |
| Correlation | Pearson's r | Multiple R |
| Variance explained | r² | R² |
| Complexity | Simple | More complex |

**Assumptions of Multiple Regression:**
1. Linear relationship between each predictor and criterion
2. No multicollinearity (predictors should not be highly correlated with each other)
3. Normality of residuals
4. Homoscedasticity (equal variance of residuals)
5. Independence of observations
