## 🔥 Core Computation: Independent Samples t-Test

**Step 1**: Compute means and SDs for each group

**Step 2**: Compute standard error of the difference between means:
$$SE_{diff} = \sqrt{\frac{SD_1^2}{n_1} + \frac{SD_2^2}{n_2}}$$

For small samples with equal variances (pooled SD):
$$t = \frac{\bar{X}_1 - \bar{X}_2}{SD_p\sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}$$

Where pooled SD:
$$SD_p = \sqrt{\frac{(n_1-1)SD_1^2 + (n_2-1)SD_2^2}{n_1+n_2-2}}$$

**Step 3**: Degrees of freedom: df = n₁ + n₂ − 2

**Step 4**: Compare t obtained with t critical at df and α = 0.05

**Decision**: If |t obtained| ≥ t critical → Reject H₀ → Significant difference

### Paired Samples t-Test (Correlated):
$$t = \frac{\bar{D}}{SE_D}$$

Where D = difference scores for each pair, D̄ = mean of differences, SE_D = SD of differences / √n

df = n − 1 (n = number of pairs)

---

## 📝 Assumptions of t-Test (Section B — ~200 words)

1. Data measured on interval or ratio scale
2. Normal distribution in the population
3. Homogeneity of variance (for independent samples)
4. Random sampling
5. Independence of observations (for independent samples t-test)

**When to use t-test vs ANOVA**: t-test compares **two groups**; ANOVA compares **three or more groups**. Running multiple t-tests inflates Type I error; ANOVA avoids this.

---

## 🧠 Memory Aid

**t-test = two groups**: t = difference between means / standard error of that difference.
