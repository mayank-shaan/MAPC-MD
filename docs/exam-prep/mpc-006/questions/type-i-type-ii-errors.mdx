## 🔥 Most Repeated Question

### Answer (Section B or C — 250/100 words):

In hypothesis testing, two types of decision errors are possible:

**Type I Error (Alpha Error — False Positive):**
A Type I error occurs when the researcher **rejects the null hypothesis when it is actually true**. The researcher concludes there is a significant effect when in reality there is none.

The probability of making a Type I error equals the significance level α. At α = 0.05, there is a 5% chance of committing a Type I error.

*Example*: Concluding that a new drug reduces anxiety when it actually has no effect (the drug doesn't work but we rejected H₀ saying it does).

**Type II Error (Beta Error — False Negative):**
A Type II error occurs when the researcher **fails to reject the null hypothesis when it is actually false**. The researcher misses a real effect.

The probability of a Type II error is denoted β. The **power** of a test = 1 − β (the probability of correctly detecting a real effect).

*Example*: Concluding that a drug has no effect when it actually does reduce anxiety (we retained a false H₀).

**Decision Matrix:**

| | H₀ True | H₀ False |
|---|---------|---------|
| **Reject H₀** | Type I Error (α) | Correct Decision (Power = 1−β) |
| **Retain H₀** | Correct Decision (1−α) | Type II Error (β) |

**Relationship between Type I and Type II Errors:**
The two errors are inversely related. Reducing α (e.g., from 0.05 to 0.01) reduces the probability of a Type I error but increases the probability of a Type II error. The researcher must balance both risks based on the consequences of each type of error in their specific context.

## 🧠 Memory Aid

- **Type I = False Alarm** (you cry wolf when there is no wolf)
- **Type II = Missed Signal** (you don't sound the alarm when there is a wolf)
- **α = probability of Type I** | **β = probability of Type II** | **Power = 1 − β**
