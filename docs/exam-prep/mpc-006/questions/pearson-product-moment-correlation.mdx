## 🔥 Core Computation Procedure

### Pearson's r — Raw Score Method

**Computation table**:

| N | X | Y | X² | Y² | XY |
|---|---|---|----|----|----|
| 1 | | | | | |
| ... | | | | | |
| Σ | ΣX | ΣY | ΣX² | ΣY² | ΣXY |

$$r = \frac{n\Sigma XY - \Sigma X \cdot \Sigma Y}{\sqrt{[n\Sigma X^2 - (\Sigma X)^2][n\Sigma Y^2 - (\Sigma Y)^2]}}$$

**Interpretation**:
- r = +1.00: Perfect positive linear correlation
- r = 0.70 to 0.99: High positive correlation
- r = 0.40 to 0.69: Moderate positive correlation
- r = 0.10 to 0.39: Low positive correlation
- r = 0: No linear correlation
- Negative values indicate inverse relationships

**Significance test**: t = r√(n−2) / √(1−r²), at df = n−2

## 📝 Characteristics of Pearson's r (Section B — ~250 words)

1. *Symmetrical*: r(X,Y) = r(Y,X) — correlation does not imply causation and does not have a direction.
2. *Standardised*: Always falls between −1 and +1.
3. *Linear only*: Measures only the degree of linear relationship; may underestimate a strong non-linear relationship.
4. *Sensitive to outliers*: Extreme values can inflate or deflate r.
5. *Scale-free*: r is not affected by the unit of measurement.
6. *Parametric*: Assumes interval/ratio data and bivariate normality.
7. *r² (coefficient of determination)*: The proportion of variance in Y explained by X (e.g., r = 0.7 → r² = 0.49 → 49% of variance explained).

**Assumptions of Pearson's r:**
- Both variables measured on interval or ratio scale
- Linear relationship between variables
- Bivariate normal distribution
- No extreme outliers

## 🧠 Memory Aid

**Correlation interpretation guide**: 0 = none, 0.1–0.3 = weak, 0.4–0.6 = moderate, 0.7–0.9 = strong, 1.0 = perfect.
