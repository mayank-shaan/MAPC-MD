## 🔥 Most Repeated Question

**Common phrasings:**

### Answer (Section A or B — ~350 words):

**Special correlations** are used when one or both variables are dichotomous (have only two categories). The choice between them depends on whether the dichotomy is **genuine** (true binary, e.g., pass/fail, male/female) or **artificial** (a continuous variable forced into two categories, e.g., above/below average).

**Point Biserial Correlation (r_pb):**

Used when one variable is **continuous** (interval/ratio) and the other is a **genuine dichotomy** (naturally two-category variable).

*Examples*: Correlation between exam score (continuous) and pass/fail status (genuine dichotomy); correlation between reaction time (continuous) and gender (genuine dichotomy).

*Formula*:
$$r_{pb} = \frac{\bar{X}_1 - \bar{X}_0}{SD_t} \sqrt{\frac{p \cdot q}{1}}$$

Where:
- X̄₁ = mean of the continuous variable for one group (coded 1)
- X̄₀ = mean of the continuous variable for the other group (coded 0)
- SD_t = standard deviation of the total group on the continuous variable
- p = proportion in group 1, q = proportion in group 0 (p + q = 1)

*Interpretation*: r_pb ranges from 0 to 1 (always non-negative or negative depending on coding). Interpreted like Pearson's r.

**Phi Coefficient (φ):**

Used when **both variables are genuine dichotomies**.

*Examples*: Correlation between gender (male/female) and treatment outcome (success/failure); passing/failing two different tests.

Data is arranged in a 2×2 contingency table:

|  | Y = 1 | Y = 0 | Total |
|--|-------|-------|-------|
| **X = 1** | a | b | a+b |
| **X = 0** | c | d | c+d |
| **Total** | a+c | b+d | n |

*Formula*:
$$\phi = \frac{ad - bc}{\sqrt{(a+b)(c+d)(a+c)(b+d)}}$$

*Relationship to Chi-square*: φ² = χ²/n (phi squared equals chi-square divided by n).

*Interpretation*: φ ranges from −1 to +1, interpreted like Pearson's r.

**Choosing the Right Correlation:**
| Variables | Use |
|-----------|-----|
| Both continuous, linear | Pearson's r |
| Continuous + genuine dichotomy | Point biserial r_pb |
| Continuous + artificial dichotomy | Biserial r_b |
| Both genuine dichotomies | Phi coefficient φ |
| Both artificial dichotomies | Tetrachoric r_t |
