## 🎯 Must-Know Concepts
1. Kruskal-Wallis is the non-parametric alternative to one-way ANOVA
2. Used when comparing three or more independent groups on ordinal data
3. Based on ranks of all scores combined
4. H statistic follows a chi-square distribution

### Answer (Section B — ~250 words):

**Kruskal-Wallis One-Way Analysis of Variance** is a non-parametric statistical test used to determine whether three or more independent groups differ significantly on a variable. It is the non-parametric equivalent of one-way ANOVA.

**When to Use:**
1. Data is measured on an ordinal scale
2. The assumptions of one-way ANOVA (normality, homogeneity of variance) cannot be met
3. Sample sizes are small
4. Comparing three or more independent groups

**Step-by-Step Computation Procedure:**

**Step 1**: Rank all scores from all groups combined, from lowest (rank 1) to highest. Handle ties with average ranks.

**Step 2**: Sum the ranks for each group: R₁, R₂, R₃, ...

**Step 3**: Apply the Kruskal-Wallis H formula:
$$H = \frac{12}{N(N+1)} \sum_{j=1}^{k} \frac{R_j^2}{n_j} - 3(N+1)$$

Where:
- N = total number of observations across all groups
- k = number of groups
- nj = number of observations in group j
- Rj = sum of ranks in group j

**Step 4**: Degrees of freedom: df = k − 1

**Step 5**: Compare H obtained with χ² critical at df = k − 1 at α = 0.05

**Decision**: If H obtained ≥ χ² critical → Reject H₀ → At least one group differs significantly

**Note on Ties**: When there are many tied ranks, a correction factor is applied to H. For small numbers of ties, the correction has minimal effect.

**Advantages over one-way ANOVA:**
- Does not require normality
- Suitable for ordinal data
- Valid for small samples

**Limitations:**
- Less powerful than ANOVA when parametric assumptions are met
- Rank-based, so loses some information from actual values
- Only tells us that groups differ — not which specific groups differ (post-hoc tests required)

---

## 🧠 Memory Aid

**Kruskal-Wallis vs ANOVA**:
- One-way ANOVA = parametric, interval/ratio data
- Kruskal-Wallis = non-parametric, ordinal/ranked data
- Both test whether 3+ groups differ; H statistic ~ χ²
