## 🌟 Comprehensive Answer: Language Comprehension Models (~500 words)

### Introduction

**Language comprehension** is the process by which listeners and readers extract meaning from spoken or written language. It is not a passive reception of information but an **active cognitive process** involving perception, memory, inference, and world knowledge. Several models have been proposed to explain how comprehension occurs — from early propositional models to the influential **Construction-Integration model** of Kintsch.

---

### Processing Levels in Comprehension

Language comprehension involves three levels of representation (Kintsch, 1998):

| Level | Description | Example |
|-------|-------------|---------|
| **Surface code** | Verbatim words and syntax | "The cat sat on the mat" |
| **Text base (propositional)** | Meaning, stripped of surface form | CAT, SIT, MAT; CAT is agent |
| **Situation model** | Mental simulation of the described event | Visualising a cat on a mat |

Skilled comprehension involves constructing all three levels, with the **situation model** being the deepest and most flexible representation.

---

### 1. Kintsch & van Dijk's Propositional Model (1978)

**Kintsch and van Dijk** proposed that text is mentally represented as a **list of propositions** — units of meaning that can be verified as true or false.

**Process:**
1. Text is divided into **cycles** of processing (working memory constraints)
2. **Propositions** are extracted from each sentence
3. A **text base** is constructed by linking propositions through coherence
4. **Macrostructure** (main idea/gist) is derived from the text base via macro-rules (deletion, generalisation, construction)

**Coherence:**
- **Local coherence**: Adjacent propositions share an argument (e.g., same person or object referred to)
- **Global coherence**: The overall text structure forms a unified discourse topic

---

### 2. Construction-Integration (CI) Model — Kintsch (1988, 1998)

The CI model is the most influential contemporary account:

**Construction Phase:**
- Words and propositions activate **associated concepts in long-term memory**, including loosely related and even irrelevant associations
- A large, loosely connected network is initially built

**Integration Phase:**
- **Constraint satisfaction** — relevant, coherent nodes become activated; irrelevant ones are suppressed
- The result is a coherent, contextually appropriate meaning representation

**Key insight**: Comprehension requires **both bottom-up** linguistic processing AND **top-down** knowledge-driven inference. The integration phase uses spreading activation and constraint satisfaction to resolve ambiguities.

---

### 3. Inference Generation

Comprehension requires generating **inferences** not explicitly stated in text:
- **Bridging inferences**: Connect current sentence to prior context ("He picked up the bat. It was wooden." → bat is cricket/baseball bat, not animal)
- **Elaborative inferences**: Add non-necessary information from world knowledge
- **Predictive inferences**: Anticipate what will happen next

---

### Interactive Models

Modern accounts (e.g., **Seidenberg & McClelland, 1989**) emphasise **parallel, interactive processing** where:
- Multiple levels of language (phonology, syntax, semantics) are processed simultaneously
- Bottom-up and top-down information interact continuously
- Context effects appear even at word recognition level

---

### Conclusion

Language comprehension is a multi-level, knowledge-dependent cognitive process. Kintsch's Construction-Integration model provides the most comprehensive framework, demonstrating that comprehension requires both constructing rich, associative representations AND integrating them through constraint satisfaction. Understanding these models has practical applications in reading education, text design, and treating language disorders.
