# MPC-006: Statistics in Psychology

## Course Overview

This course covers statistical methods essential for psychological research, including descriptive statistics, inferential statistics, and data analysis techniques.

## Course Structure

### Block 1: Parametric and Non-Parametric Statistics
- Parametric and Non-Parametric Statistics
- Assumptions and Scales of Measurement
- Parametric Tests (t-test, F-test, Pearson correlation)
- Non-Parametric Tests (Chi-square, Mann-Whitney U)

### Block 2: Probability & Distributions
- Probability Concepts
- Normal Distribution
- Sampling Distributions
- Hypothesis Testing Basics

### Block 3: Inferential Statistics
- t-Tests
- Analysis of Variance (ANOVA)
- Correlation
- Regression Analysis

### Block 4: Advanced Topics
- Chi-Square Tests
- Non-Parametric Tests
- Factor Analysis
- Using Statistical Software

## Learning Objectives

By the end of this course, you will be able to:
- 🎯 Apply appropriate statistical techniques to psychological data
- 🎯 Interpret statistical results correctly
- 🎯 Use statistical software for data analysis
- 🎯 Report statistical findings properly
